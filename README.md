# Кофейня «Кремка»

Веб-приложение для онлайн-заказа кофе, десертов и выпечки с акцентом на современный UI/UX-дизайн. Разработан в рамках учебной практики.

**Выполнила:** Филиппова Лина, группа 9ИС-370.

## 🛠 Стек технологий
*   **Backend:** C# (ASP.NET Core, .NET 7)
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript (SPA-архитектура)
*   **База данных:** SQLite (файл `coffee.db`)

## 📌 Основные возможности
*   **Клиент:** просмотр каталога с фильтрами, корзина (сохраняется в localStorage), оформление заказа (самовывоз/доставка), просмотр блога о кофе, генерация электронных чеков.
*   **Администратор:** управление товарами, статьями блога, заказами и просмотр аналитики (графики на чистом SVG без сторонних библиотек).
*   **Уникальная фишка:** интерактивная **Drag-and-Drop система стикеров**, позволяющая прикрепить к заказу пожелания (например, «Срочно», «Подарок», «Без сахара»).

1.  Установите [.NET SDK 7] (или новее).
2.  Откройте папку с проектом в VS Code.
3.  Откройте терминал и выполните команду:
    ```bash
    dotnet run
Перейдите в браузере по адресу: http://localhost:5090.

При первом запуске автоматически создается файл базы данных coffee.db и заполняется тестовыми данными (товары, категории, пользователи и статьи для блога).
